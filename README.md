# MiniMax H3 — Sampler comparison

Every sampler of MiniMax H3 rendered on the same clip — same weights, same seed,
same everything — so the only variable between videos is the sampler.

- **Scene:** The Yellow King — Multishot Test (6 s · 0.4 MP 16:9 · 32 frames · 24 fps · scheduler `sgm_uniform`)
- **Author:** [LuisaCaotica](https://github.com/Luisacaotica)
- **Status:** 🚧 work in progress — clips land here as they finish rendering

Live site: `https://luisacaotica.github.io/minimax-h3-sampler-eval/`

## Pages

| Page | What it does |
|---|---|
| `index.html` | Project info, fixed render settings, models, status |
| `samplers.html` | All 241 samplers side by side — search, rendered-only filter, size control, pagination |
| `ab.html` | A/B wipe slider between any two rendered samplers (drag to wipe, keys `a`/`b` for audio, `s` to swap) |

## Layout

```
index.html, samplers.html, ab.html   the three pages
style.css                            shared neocities-flavoured dark theme
data.js                              scenes + sampler list + RENDERED (single source of truth)
gfx/                                 neocities assets (tiled background, dividers, nav buttons, thank-you bar)
videos/<scene>--<sampler>.mp4        rendered clips
posters/<scene>--<sampler>.jpg       frame-1 thumbnails (generated by the sync script)
tools/sync_videos.py                 copy ComfyUI renders in, keep data.js in sync
```

## Adding new renders

ComfyUI writes clips as `<sampler>_00001.mp4` into its output folder
(e.g. `res_multistep_00001.mp4`). Drop the renders wherever you like, then:

```bash
python tools/sync_videos.py --source "C:/path/to/ComfyUI/output/samplertest"
```

This copies each newest `<sampler>_00001.mp4` to `videos/<scene>--<sampler>.mp4`,
generates poster thumbnails (needs `ffmpeg`, otherwise skipped), and rewrites the
`RENDERED` list in `data.js` — the pages update automatically, and samplers without
a clip still show a "still rendering…" placeholder.

Prefer doing it by hand? Just drop `videos/<scene>--<sampler>.mp4` and add the
sampler name to `RENDERED` in `data.js`.

Adding a second scene later = add a scene entry in `data.js` + drop videos as
`videos/<new-scene>--<sampler>.mp4`.
